Smart Pantry Manager 

Name: Thato Mahlake
App: Smart Pantry Manager

My Smart Pantry Manager mobile application designed to help users manage household food ingredients. It allows users to capture every ingredient added on the pantry, quantities, measurement units and manages expiry dates. It helps users know how much quantity of ingredients is needed to be bought, so that not a lot is left over leading to food waste. Users can view and manage their pantry inventory and receive recipe suggestions based on the ingredients available to them.

Database: SQLite
I choose Sqlite because it is lightweight and it does not need any external databases application. It will store all the pantry ingredient and recipes locally, It can create structured tables tables and SQL queries to manage ingredient and recipes. It made it easier to connect my pantry to the database and create a strict matching recipe.
